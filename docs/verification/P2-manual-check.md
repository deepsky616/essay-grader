# P2 검증 기록

검사 날짜: 2026-08-16

설계 기준: `docs/specs/2026-08-15-architecture-design.md`의 2절, 5절, 7.1절부터 7.7절, 10절, 11절, 12절, 14절.

## 결론

P2의 코드, 합성 자료 자동 검사, 제품 빌드와 지역 브라우저 검사는 완료했다. 현재 작업 환경에는 실제 프린터, 스캐너, 필기한 답안지가 없으므로 실물 결과는 실행하지 않은 상태다. 아래 칸에는 추정값을 넣지 않았으며, 장비와 시험 답안이 준비되면 같은 문서에 관찰값을 추가해야 P2의 현장 검증이 끝난다.

## 실행한 검사

| 검사 | 결과 |
|---|---|
| 전체 백엔드 시험 | 596개 성공 |
| 스캔 API 집중 시험 | 13개 성공 |
| 파이썬 `compileall` | 성공 |

| 중간 등급 이상 의존성 감사 | 취약점 0건 |

| 영역판과 원본 그림 폭 일치 | 큰 화면과 390화소 화면 모두 성공 |
| 390화소 화면 가로 넘침 | 영역과 스캔 화면 모두 0건 |
| 브라우저에서 지역 파일 선택 | 브라우저 확장 파일 접근 권한이 없어 미실행 |

## 자동 검사로 확인한 안전 경계

- 마커 쪽 수열에 누락, 중복, 순서 오류가 있으면 학생 제출을 하나도 만들지 않는다.
- 응시 인원은 명렬표에서 결시자를 빼 계산한다.
- 응답 영역과 식별정보 영역이 한 화소라도 겹치면 저장과 크롭 생성을 거절한다.
- 이름과 번호 영역은 지역 실행 파일에만 넘기며 외부 전송용 크롭에 포함하지 않는다.
- 명렬표 이름이 응답 본문에서 발견되거나 명렬표 조회가 실패하면 외부 전송을 닫아서 막는다.
- 이름 읽기 결과가 명렬표에서 유일하지 않으면 임의 배정하지 않고 교사 확인 상태로 둔다.
- 두 학생 배정이 뒤바뀌었을 때 같은 배치 안에서 원자적으로 맞바꾸며 임시 자료를 남기지 않는다.
- 새 배부용 답안지는 네 모서리 마커를 우선 사용하고, 마커가 전혀 없는 기존 양식만 특징점 정합을 쓴다.

## 실물 결과표

상태: 실제 출력 장비와 필기 답안이 없어 미실행.

| 항목 | 결과 | 확인 기준 |
|---|---|---|
| 마커 검출 성공률 | 미실행 | 인쇄된 모든 쪽에서 네 개 모두 검출 |
| 정합 품질 | 미실행 | `registration_quality` 0.9 이상 |
| 검정 볼펜 필기 추출 | 미실행 | 답안 보존, 인쇄 격자선 제거 |
| 검정 사인펜 필기 추출 | 미실행 | 답안 보존, 번짐이 경계를 넘지 않음 |
| HB 연필 필기 추출 | 미실행 | 옅은 획이 끊기지 않음 |
| 이름란 지역 글자 읽기와 명렬표 맞추기 | 미실행 | 확인된 인원과 전체 인원 기록 |
| 문항 크롭 경계 | 미실행 | 답안 획이 잘리지 않음 |
| 한 쪽 삭제 주입 | 미실행 | `split_failed`, 제출 0개, 어긋난 쪽 안내 |
| 한 쪽 복제 주입 | 미실행 | `split_failed`, 제출 0개, 어긋난 쪽 안내 |

## 장비가 준비됐을 때 남은 절차

1. 빈 답안지에서 식별정보 영역 하나와 모든 문항 응답 영역을 지정하고 배부용 PDF를 만든다.
2. 실제 크기로 인쇄해 네 마커와 주변 흰 여백이 잘리지 않았는지, 응답 상자가 원문을 가리지 않는지 확인한다.
3. 검정 볼펜, 검정 사인펜, HB 연필로 같은 수준의 답안을 각각 작성한다.
4. 300dpi 회색조로 여러 학생분을 이어 스캔해 하나의 PDF로 만든다.
5. 정상 PDF를 올려 위 표의 검출률, 정합 품질, 필기 추출, 이름 맞추기와 크롭 경계를 기록한다.
6. 같은 PDF에서 중간 쪽 하나를 지운 사본과 하나를 복제한 사본을 각각 올린다.
7. 두 사고 배치가 모두 `split_failed`이고 제출이 0개인지 데이터베이스와 화면에서 확인한다.
8. 세 필기구 결과를 바탕으로 권장 필기구를 정한다. 연필 획 손실이 보이면 운영 안내를 검정 볼펜 또는 사인펜으로 제한한다.

실물 확인이 끝나면 `미실행` 칸만 실제 관찰값으로 바꾸고 별도 검증 커밋을 남긴다.
