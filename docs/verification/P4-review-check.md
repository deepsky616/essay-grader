# P4 교사 검토 확인 기록

확인 날짜: 2026-08-16

설계 기준: `docs/specs/2026-08-15-architecture-design.md`의 7.7절, 8절,
10절, 12절부터 14절.

## 결론

문항 단위 검토, 점수 확정과 수정 이력, 자동 경로 일괄 확정, 실제 전체 페이지
보기, 문항과 유형별 제안 일치율, 학생별 현재 총점 구현은 완료했다. 전체 백엔드
검사 801개와 프런트엔드 제품 빌드가 성공했다.

현재 작업 공간에는 실제 한 학급 답안, 교사가 직접 확정한 대조 점수, 같은 답안을
종이로 채점한 기준 시간이 없다. 따라서 검토 속도와 현장 일치율은 측정하지 않았고,
아래의 합성 자료 확인값을 현장 근거로 사용하지 않는다.

## 합성 자료 확인에서 본 화면 동작

합성 학생 두 명과 문항 두 개, 점수 네 건으로 화면 동작만 확인했다. 닫힌 단답
한 건을 숫자키로 수락한 뒤 진행률이 0/4에서 1/4로 바뀌고 다음 학생이 표시됐다.
이 표본에서 자동 경로 수정은 0건이었지만, 합성 자료 한 건이므로 정확도나 자동
확정 기준의 근거가 아니다.

- 크롭과 전체 페이지가 모두 잘리지 않고 표시됐다.
- 긴 채점 기준은 점수 선택 단추 안에서 줄바꿈됐다.
- 그림 문항은 학생 답안과 펼칠 수 있는 예시 답안을 같은 화면에 표시했다.
- 숫자키 확정과 방향키 이동이 작동했다.
- 휴대폰 너비에서는 채점 기준이 답안 아래로 내려가고 전체 화면 가로 넘침이 없었다.

## 실제 자료가 준비됐을 때 남은 절차

1. P3 파일럿에서 만든 실제 학생 답안 스무 장부터 서른 장과 교사 대조 점수를 준비한다.
2. 같은 답안을 종이에서 문항 단위로 채점하고 문항마다 시간을 잰다.
3. 앱에서 미확정만 보기와 키보드 단축키를 사용해 한 학급 전체를 중단 없이 확정한다.
4. 위 표에 문항별 건수, 앱 시간, 건당 평균, 종이 시간을 기록한다.
5. 전체 페이지를 연 횟수와 크롭 누락, 기준 문장 스크롤, 그림 비교 불편을 기록한다.
6. 자동 경로 수정이 한 건이라도 있으면 신뢰도 기준을 올리거나 해당 유형을 제외한다.
7. 문항과 유형별 표본 수를 함께 남기고, 표본이 없는 일치율을 안전 근거로 쓰지 않는다.
8. 앱이 종이보다 느린 문항은 화면 흐름을 고친 뒤 같은 자료로 다시 잰다.

실제 검토를 끝내면 이 문서의 `미실행` 값만 관찰값으로 바꾸고 별도 검증 커밋을
남긴다.
