# P4 구현 보고서

## 결과

- 확정 수락과 수정과 다시 확정을 모두 남기는 점수 이력
- 자동 경로만 대상으로 하는 원자적 일괄 확정
- 선택한 채점 실행에 한정된 학생별 현재 총점
- 실제 교사 이력만 표본으로 쓰는 문항과 유형별 제안 일치율
- 성공한 실행과 확정 루브릭만 받는 문항 단위 검토 API
- 지역 배치 저장소의 링크가 아닌 피엔지 크롭과 정합 페이지 제공
- 문항 단위 이동, 숫자와 엔터 단축키, 전체 페이지 전환, 중복 입력 잠금
- 표본 없음과 자동 경로 이견을 구분하는 반응형 보고서

## 설계 반영

- 7.7절에 따라 학생 이미지는 지역 저장소에서만 읽고 제공하며 외부 전송을 추가하지 않았다.
- 8절에 따라 학생별이 아닌 문항별 큐를 만들고 크롭, 전체 페이지, 기준, 예시 답안, 단축키를 한 흐름에 배치했다.
- 8절과 10절에 따라 제안을 그대로 수락한 경우도 이전값과 새값, 지역 교사 주체와 시각을 남긴다.
- 13절에 따라 빈 표본이나 합성 한 건을 안전 근거로 표시하지 않고 실제 답안 스무 장부터 서른 장의 검토를 요구한다.
- 14절의 스캔 운영 결과를 확인할 수 있도록 잘린 크롭에서 실제 정합 전체 페이지로 전환한다.

## 검사

- 전체 백엔드 검사 801개 성공
- 프런트엔드 엄격 자료형 검사와 제품 빌드 성공, 50개 모듈
- 프런트엔드 배포 의존성 취약점 0건
- 넓은 화면과 390화소 화면에서 크롭, 전체 페이지, 단축키, 수동 문항과 보고서 확인
- 지정 저장소 밖 파일과 기호 링크 차단 확인
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 실제 한 학급 검토 속도와 종이 채점 비교는 실제 답안과 교사 시간이 필요하다.
- 실제 학생 답안의 문항과 유형별 제안 일치율이 쌓이기 전에는 전체 검토 모드를 유지해야 한다.
