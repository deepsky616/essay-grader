# 작업 17 보고서

상태: 자동화 가능한 검증과 수동 검증 준비 완료. 실제 외부 컴파일만 입력 자료 부재로 미실행이다.

## 자료 확인

- 저장소 안 PDF: 없음
- 저장소 안 HWP와 HWPX: 없음
- 작업 입력으로 제공된 개인 API 키: 없음
- 개인 키체인이나 암호화 저장소를 임의로 읽지 않음

## 실행

- 전체 백엔드 시험 334개
- 외부 전송, 컴파일러, 루브릭 API, 설정, 경고 초점 시험 134개
- 파이썬 전체 컴파일 검사
- 타입스크립트 엄격 검사와 Vite 제품 빌드
- 중간 등급 이상 의존성 감사
- 격리된 임시 자료로 실제 브라우저 저장, 확정, 해제, 직접 주소 새로고침, 반응형, 입력 이름 검사

## 판정

Ruling: 실제 예시 자료와 개인 API 키가 없으면 외부 컴파일 성공이나 여덟 문항 결과를 추정해 쓰지 않는다 — 검증 기록의 진실성과 개인 자격 정보 경계를 지키기 위해서다 — 이 판단이 틀리면 P1 실제 자료 완료 표시는 입력이 제공될 때까지 남는다.

## 산출물

- `docs/verification/P1-manual-check.md`에 실행 증거, 설계 안전 경계, 미실행 대조표, 자료 준비 뒤 남은 절차를 기록했다.
