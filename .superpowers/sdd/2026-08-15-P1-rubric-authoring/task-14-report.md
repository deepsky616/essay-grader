# 작업 14 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- Vite, React, 타입스크립트 프런트 틀과 재현 가능한 의존성 잠금 파일
- 지역 FastAPI로만 이어지는 개발 중계와 백엔드 정적 폴더 빌드 출력
- 백엔드 루브릭, 평가, 문서, 설정 응답과 맞춘 엄격한 공용 자료형
- 평가, 문서, 루브릭, 확정 해제, 설정 전체 API 손잡이
- 문자열, 구조화 오류, 204 응답을 안전하게 처리하는 공용 요청 함수
- 브라우저 뿌리 영역 확인과 네 화면 경로 빈 틀
- 빌드 산출물과 타입스크립트 증분 자료 제외 규칙

## 판정

Ruling: 최초 계획의 React Router 6 계열 대신 7.18 이상을 사용한다 — 설치 감사에서 6 계열 전체에 걸친 중간 등급 이동 경로 취약점 두 건이 확인됐고, 현재 쓰는 공개 구성 요소는 7 계열 빌드를 그대로 통과했기 때문이다 — 이 판단이 틀리면 뒤 화면에서 바뀐 라우터 동작을 맞춰야 한다.

Ruling: 백엔드 정적 빌드 결과는 저장소에 넣지 않고 소스와 잠금 파일에서 다시 만든다 — 해시 이름 큰 파일의 반복 변경을 피하고 하나의 정본을 프런트 소스로 유지하기 위해서다 — 이 판단이 틀리면 배포 전에 `npm run build`를 반드시 실행해야 한다.

Ruling: API 오류 전체를 문자열로 직렬화하지 않고 백엔드가 허용한 문자열이나 첫 검증 메시지만 표시한다 — 입력값과 내부 구조가 화면 오류를 거쳐 되비치는 일을 줄이기 위해서다 — 이 판단이 틀리면 여러 검증 오류 가운데 첫 항목만 바로 보인다.
