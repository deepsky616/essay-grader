# 작업 2 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 62쪽과 네 모서리의 마커 번호 왕복 변환
- 248과 249 예약 번호와 잘못된 정수 입력 거절
- 8비트 이진 마커 생성과 안전한 최소 크기
- 회색, BGR, BGRA 이미지 입력 검사
- 회전과 축소 뒤 네 모서리와 쪽 번호 검출
- 일부 마커 검출과 빠진 물리 모서리 이름
- 서로 다른 쪽 혼합과 같은 모서리 중복의 닫힌 실패
- 바꿀 수 없는 검출 좌표 매핑

## 검사

- 마커 순수 함수 시험: 30개 성공
- 전체 백엔드 시험: 382개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 합성 이미지의 4도 회전과 0.92 축소는 통과했지만 실제 인쇄 번짐과 카메라 왜곡은 작업 18 실물 측정이 필요하다.
- 마커 하나의 오검출도 혼합 쪽으로 닫아 실패하므로 검출기 임계값은 실제 스캔 자료로 조정해야 한다.
