# 작업 5 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 넓은 흐림 배경을 이용한 스캔과 템플릿의 조명 정규화
- 템플릿보다 충분히 어두워진 화소만 필기 후보로 선택
- 템플릿 인쇄 요소를 세 화소 반경으로 팽창해 작은 정합 오차 흡수
- 작은 점 잡음 제거와 이진 잉크 마스크 생성
- 회색, BGR, BGRA 입력과 크기, 자료형, 화소 수 검사
- 입력 불변과 읽기 전용 결과 보장
- 이진 마스크만 받는 잉크 비율 및 백지 판정

## 검사

- 필기 추출 시험: 15개 성공
- 균일한 밝기 이동, 완만한 밝기 기울기, 1.5화소 이동 시험 성공
- 전체 백엔드 시험: 428개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 템플릿 선 위에 정확히 겹쳐 쓴 필기는 인쇄 요소 마스크와 함께 일부 사라질 수 있다.
- 연필과 흐린 펜의 임계값은 설계 문서 13절과 작업 18의 실제 스캔 표본 측정이 필요하다.
