# 작업 9 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 엄격한 문항 번호와 정수 사각형 자료형
- 회색, BGR, BGRA의 8비트 페이지 및 크기 제한
- 페이지 안쪽의 유효한 식별정보 사각형 검사
- 응답과 식별정보의 한 화소 이상 겹침 차단
- 페이지 밖으로 일부 나간 응답 영역의 안전한 잘라내기
- 페이지 밖에 완전히 놓인 응답 영역 거절
- 여러 크롭의 중복 문항 번호 거절
- 원본과 메모리를 공유하지 않는 읽기 전용 크롭
- 바꿀 수 없는 문항별 크롭 매핑

## 검사

- 크롭 생성 시험: 23개 성공
- 겹침, 경계 접촉, 부분 잘라내기, 중복 문항과 잘못된 식별정보 영역 시험 성공
- 전체 백엔드 시험: 504개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 식별정보 사각형 자체가 교사에 의해 너무 작게 지정되면 실제 이름 획이 응답 영역으로 삐져나올 수 있다.
- 화면에서 식별정보 영역에 안전 여백을 권장하고 실제 양식으로 경계 표본을 확인해야 한다.
