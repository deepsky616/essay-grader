# 작업 13 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 평가의 최신 빈 답안지 문서로 템플릿 생성
- 같은 원본 재호출의 멱등 처리
- 새 원본 선택 시 기존 영역과 인쇄 준비 상태 무효화
- 안전한 업로드 폴더 바로 아래 일반 파일 경계
- 실제 PDF, 암호 여부, 쪽 수와 200 dpi 렌더 화소 제한 재검사
- 비공개 캐시 지시가 있는 페이지 PNG 제공
- 영역 자료형, 좌표, 페이지 경계, 문항 중복과 식별정보 겹침 검사
- 관계 목록 기반 원자적 영역 교체와 즉시 조회 일관성
- 고유한 배부용 PDF 이름과 600 파일 권한
- 생성 PDF의 마커, 응답 박스와 고정 내려받기 응답
- 지역 저장 경로와 잘못된 파일 내용 숨김

## 검사

- 답안지 생성기와 템플릿 API 집중 시험: 35개 성공
- 생성, 재호출, PNG, 영역 교체, 겹침, 새 원본, 인쇄 PDF와 경로 변조 시험 성공
- 전체 백엔드 시험: 576개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 새 원본이나 새 영역으로 인쇄 PDF 참조가 바뀔 때 예전 생성 파일은 안전상 자동 삭제하지 않아 보관 폴더에 남는다.
- 실제 브라우저 영역 편집기의 좌표 반올림과 PDF 포인트 변환은 작업 16과 작업 18에서 함께 확인해야 한다.
