# 작업 17 보고서

상태: 완료. 주 에이전트가 구현, 전체 검사, 브라우저 화면 검사를 함께 수행했다.

## 구현

- 명렬표 붙여넣기, 미리보기, 결시 표시, 저장과 저장된 학급 목록
- 학급 자료가 지역에만 남는다는 식별정보 안내
- 평가별 스캔 배치 화면, 100MB 파일 제한, 처리 상태 폴링과 실패 안내
- 처리 완료 뒤 학생 제출 목록과 배정 확인 상태 표시
- 이미 배정된 학생끼리도 바로잡을 수 있는 원자적 배정 맞바꾸기
- 맞바꾸기 도중 데이터베이스 유일성 제약을 지키는 임시 학생과 같은 트랜잭션 안의 제거
- 작은 화면에서 올리기 입력을 세로로 배치하고 넓은 표만 자체 스크롤
- 영역 지정 화면과 스캔 배치 화면 사이 이동 길

## 설계 연결

- 설계 문서 5절의 단일 컴퓨터 지역 자료 경계
- 설계 문서 7.1절의 급지 사고 전체 중단과 학생별 분할
- 설계 문서 7.7절의 식별정보 외부 전송 금지
- 설계 문서 10절의 학생, 배치, 제출 소유 관계
- 설계 문서 14절의 명렬표와 배치 검토 화면

## 검사

- 스캔 API 집중 시험: 13개 성공
- 이미 배정된 두 학생의 맞바꾸기와 임시 학생 제거 시험 성공
- 전체 백엔드 시험: 596개 성공
- 프런트엔드 엄격 자료형 검사와 운영 빌드 성공
- 프런트엔드 의존성 검사: 알려진 취약점 없음
- 브라우저에서 명렬표 읽기, 저장 학급 표시, 영역 지정 화면, 배치 화면 이동 확인
- 390화소 너비에서 스캔 배치와 영역 지정 화면의 가로 넘침 없음
- 브라우저 검사에서 영역판과 원본 그림 폭 차이를 찾아 고친 뒤 큰 화면과 작은 화면에서 다시 일치 확인
- 브라우저 확장의 지역 파일 접근 권한이 꺼져 있어 파일 선택은 수행하지 못했으며, 같은 올리기와 상태 전이 경로는 API 시험으로 확인
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 실제 출력물과 스캐너에서의 마커 품질, 필기구별 차분 품질은 작업 18의 장비 확인이 필요하다.
- 아주 큰 명렬표와 느린 저장 장치에서의 화면 반응 시간은 현장 자료로 다시 살펴볼 필요가 있다.
