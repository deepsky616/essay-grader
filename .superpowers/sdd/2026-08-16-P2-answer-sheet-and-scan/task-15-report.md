# 작업 15 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 모든 학급과 결시자를 포함한 학생 이름 조회
- 두 글자 미만 이름 제외와 앞뒤 공백 정리
- 호출마다 독립 데이터베이스 세션 생성
- 성공과 조회 실패 모두에서 세션 닫기
- 조회 실패를 전송 관문까지 전파하는 닫힘 실패
- 루브릭 생성 전송 관문에 실제 명렬표 공급자 연결
- 이름 집합을 외부 요청과 감사 기록에 넣지 않는 기존 관문 유지

## 설계 연결

- 설계 문서 7.7절 외부 전송 경계
- 설계 문서 7.7절 4번 답안 본문 실명 노출 감지
- 결시자 답안이 잘못 섞일 가능성까지 고려해 결시자 이름도 차단 목록에 포함

## 검사

- 용어 공급자와 루브릭 연결 집중 시험: 35개 성공
- 최신 이름, 여러 학급, 결시자, 빈 자료, 짧은 이름 시험 성공
- 호출별 새 세션과 정상 및 실패 닫힘 시험 성공
- 전체 백엔드 시험: 595개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 한 글자 이름은 오탐을 줄이기 위해 제외하므로 실제 한 글자 학생 이름은 문자열 검사로 막지 못한다. 응답 크롭의 식별정보 영역 배제와 지역 처리 경계가 함께 지켜져야 한다.
- 현재 이름 집합은 모든 학급에서 읽는다. 학급 수가 매우 커지면 평가에 연결된 학급만 좁히되 누락 없이 차단하는 구조를 따로 재야 한다.
