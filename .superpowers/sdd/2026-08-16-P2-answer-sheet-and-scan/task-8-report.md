# 작업 8 보고서

상태: 구현 완료. 현재 기기에는 지역 인식 실행 파일이 없어 실제 한국어 인식 확인은 남아 있다.

## 구현

- 식별정보 영역 전용 로컬 인식 프로토콜과 Tesseract 구현
- 회색, BGR, BGRA의 8비트 이미지 및 화소 수 검사
- 회색 복사본만 인식기로 전달해 입력 불변 보장
- 한국어 자료와 한 줄 인식 모드 고정
- 10초 실행 제한
- 실행 파일 없음, 언어 자료 오류, 시간 초과의 고정 오류 변환
- 원래 오류 메시지와 지역 경로 숨김
- 결과 문자열 자료형과 200자 길이 제한
- 입력 복사본을 기록하는 시험 대역

## 검사

- 로컬 인식 손잡이 시험: 10개 성공
- 빠진 실행 파일, 실행 오류 경로 숨김, 모드 전달, 잘못된 입력과 결과 시험 성공
- 전체 백엔드 시험: 481개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 현재 기기에서 `tesseract` 실행 파일을 찾지 못해 실제 한국어 이름 이미지는 확인하지 못했다.
- 설치 뒤 실제 이름란 표본으로 인식률을 측정하고 명렬표 매칭까지 이어지는 통합 시험이 필요하다.
