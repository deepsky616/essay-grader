# 작업 12 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 번호와 이름을 공백 또는 탭으로 나눈 명렬표 붙여넣기
- 빈 줄 무시와 실제 줄 번호 오류 안내
- 오류 응답에서 읽지 못한 원문 이름 숨김
- 명렬표 본문 길이와 학급당 500명 제한
- 중복 학생 번호의 붙여넣기 및 생성 단계 차단
- 엄격한 학생 번호, 이름, 결시 여부와 추가 필드 거절
- 학급 생성, 최신 순 목록, 단건 조회
- 학생 이름과 결시 여부 수정
- 학급과 학생의 소속 경계 확인
- 빈 수정과 빈 이름 거절
- 자료 무결성 충돌의 고정 오류 변환

## 검사

- 명렬표와 학급 API 시험: 15개 성공
- 붙여넣기, 공백, 잘못된 줄, 중복, 생성, 목록, 조회, 수정과 소속 경계 시험 성공
- 전체 백엔드 시험: 558개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 이름이 같은 학생은 학급 API에서는 허용되며 뒤 배정 단계에서 번호 또는 교사 확인이 필요하다.
- 스프레드시트의 복잡한 여러 열 붙여넣기는 지원하지 않고 번호와 이름 두 열만 받는다.
