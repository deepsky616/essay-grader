# 작업 10 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 평가별 답안지 템플릿과 응답 및 식별정보 영역
- 학급과 번호 순 학생 및 결시자 도움 함수
- 스캔 배치와 학생별 제출, 쪽 이미지, 문항 응답
- 상태값, 쪽 수, 좌표, 페이지 범위와 정합 품질 검사 제약
- 비어 있지 않은 이름과 지역 경로 검사 제약
- 평가별 템플릿과 학급별 번호 등 중복 방지 제약
- 제출별 익명 표식의 전체 유일성과 형식 제약
- 평가, 학급, 배치 소유 자료의 외래 키 삭제 연쇄
- 원본 답안지 문서 삭제 시 템플릿 보존과 참조 비우기
- 새 모델의 묶음 내보내기

## 검사

- P2 데이터 모델 시험: 21개 성공
- 관계 저장, 정렬, 제약 위반, 중복, 삭제 연쇄와 참조 비우기 시험 성공
- 전체 백엔드 시험: 525개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 새 표는 기존 데이터베이스에도 자동 생성되지만, 앞으로 이 표들의 열을 바꿀 때는 별도 반복 가능 이동 절차가 필요하다.
- 학생 이름이 같은 경우 자료 모델만으로 배정을 구분할 수 없어 번호 인식이나 교사 확인이 계속 필요하다.
