# 작업 16 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 템플릿, 영역, 배부용 파일 프런트엔드 자료형과 호출 손잡이
- 루브릭 화면에서 영역 지정 화면으로 가는 실제 이동 길
- 마우스와 터치를 함께 지원하는 포인터 드래그
- 표시 크기에서 원본 답안지 화소로 좌표 변환과 경계 고정
- 쪽 전환과 원본 이미지 크기 갱신
- 응답 영역, 식별정보 영역 색 구분과 쪽별 목록
- 중복 문항, 둘째 식별정보 영역, 교차 겹침과 작은 영역 사전 거절
- 개별 영역과 현재 쪽 전체 지우기
- 저장하지 않은 변경, 오류와 성공 안내
- 식별정보 영역을 배부용 파일 생성의 서버 필수 조건으로 보강
- 새 창이 막혀도 다시 쓸 수 있는 내려받기 링크

## 설계 연결

- 설계 문서 7.7절 1번 식별정보 영역 지정
- 설계 문서 7.7절 2번 지역 전용 처리
- 설계 문서 7.7절 3번 식별정보 영역 전송 배제
- 설계 문서 14절 템플릿 영역 지정 화면

## 검사

- 템플릿 API 집중 시험: 19개 성공
- 식별정보 영역 없는 배부용 파일 생성 거절 시험 성공
- 전체 백엔드 시험: 596개 성공
- 프런트엔드 엄격 자료형 검사와 운영 빌드 성공
- 프런트엔드 의존성 검사: 알려진 취약점 없음
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 실제 답안지 이미지에서 여러 화면 너비와 터치 입력을 쓰는 브라우저 검사는 작업 17 화면과 함께 진행해야 한다.
- 정확한 식별정보 영역 여백은 실제 학교 양식과 스캔 흔들림 표본으로 확인해야 한다.
