# 작업 4 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 네 모서리 마커 중심 대응과 투시 변환 기반 정합
- 스캔과 템플릿의 쪽 번호 일치 강제
- 일부 마커와 혼합 마커의 닫힌 실패
- 양쪽 모두 무마커인 기존 양식용 ORB 특징점과 RANSAC 대체 경로
- 최소 특징점 대응 수, 인라이어 수와 비율 검사
- 유한성, 행렬식, 조건 수에 따른 변환 행렬 검사
- 입력 자료형, 채널 수, 크기와 전체 화소 수 제한
- 템플릿 크기의 회색 8비트 읽기 전용 결과와 정합 방식 및 품질 반환

## 검사

- 페이지 정합 시험: 14개 성공
- 회전, 축소, 이동, 크기 변경과 투시 왜곡 복원 성공
- 전체 백엔드 시험: 413개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 마커 방식의 네 대응점 재투영 오차는 수학적으로 매우 작으므로 품질 점수가 실제 인쇄 번짐을 충분히 나타내지 못할 수 있다.
- 특징점 임계값은 합성 양식에서 확인했으며 실제 학교 양식 표본으로 조정해야 한다.
