# 작업 3 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 최대 62쪽의 네 모서리에 쪽 번호와 모서리를 함께 나타내는 마커 삽입
- 200 dpi에서 한 변 50화소 이상이 되는 인쇄 크기와 흰 여백 적용
- 문항별 응답 영역 박스 삽입
- 쪽 수, 용지 크기, 영역 쪽 번호, 유한 좌표, 양의 크기, 용지 경계 검사
- 응답 영역과 마커 흰 여백의 겹침 거절
- 원본과 출력의 같은 경로 거절과 오류 메시지의 지역 경로 숨김
- 임시 파일 저장, 완성 PDF 쪽 수 재검사, 원자적 출력 교체

## 검사

- 답안지 생성기 시험: 17개 성공
- 200 dpi로 다시 그린 세 쪽에서 네 마커와 쪽 번호 검출 성공
- 전체 백엔드 시험: 399개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 합성 PDF에서 검출은 확인했지만 실제 프린터의 축소, 번짐, 잘림은 작업 18의 실물 측정이 필요하다.
- 암호, 전자 서명, 특수 색 공간을 쓰는 현장 PDF 표본이 없어 해당 입력은 실제 표본으로 추가 확인해야 한다.
