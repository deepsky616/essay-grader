# 작업 7 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 유니코드 호환 정규화와 모든 공백 및 보이지 않는 형식 문자 제거
- 삽입, 삭제, 치환 기반 실제 편집 거리 계산
- 이름 길이에 비례한 최대 허용 거리
- 유일한 최소 거리 후보만 일치로 확정
- 동점과 정규화 중복 이름의 애매함 처리
- 빈 인식과 빈 명렬표의 불일치 처리
- 원문과 정규화 이름 길이 및 명렬표 인원 제한
- 입력 명렬표 불변 보장

## 검사

- 명렬표 매칭 시험: 17개 성공
- 정확 일치, 한 글자 오류, 삽입, 삭제, 동점, 중복 이름, 유니코드 분해 입력 시험 성공
- 전체 백엔드 시험: 471개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 같은 이름 학생은 이름만으로 절대 확정할 수 없으므로 번호 영역 인식이나 교사 확인이 필요하다.
- 실제 로컬 OCR의 글자 혼동 분포를 얻으면 글자별 비용을 둔 거리 방식이 더 나을 수 있다.
