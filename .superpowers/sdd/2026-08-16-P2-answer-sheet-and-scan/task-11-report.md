# 작업 11 보고서

상태: 완료. 작업 수 한도로 주 에이전트가 구현과 읽기 전용 검토를 함께 수행했다.

## 구현

- 스캔, 템플릿, 쪽 수, 영역, 명렬표와 손잡이의 선행 계약 검사
- 마커 양식의 쪽 번호 우선 선택과 정합
- 양쪽 모두 무마커인 기존 양식의 특징점 후보 비교
- 마커 양식과 무마커 양식 혼합 거절
- 쪽 번호 수열 검증 뒤에만 학생 분할
- 급지 및 정합 실패의 학생 결과 없는 전체 중단
- 조명과 정합 오차를 보정한 필기 추출
- 식별정보 경계가 강제된 원본 및 잉크 문항 크롭
- 이름 영역만 로컬 인식 후 명렬표 닫힌 집합 대조
- 다른 학생 이름을 읽어도 자동 재배정하지 않는 검토 상태
- 로컬 인식 불가 시 해당 학생만 검토 상태
- 고정 전체량과 단조 증가하는 정합 진행률

## 검사

- 스캔 파이프라인 시험: 18개 성공
- 정상, 이름 불일치, 다른 학생 이름, 인식 불가, 급지 사고, 정합 실패와 인원 불일치 시험 성공
- 실패 전 이름 인식 미호출과 입력 스캔 불변 시험 성공
- 전체 백엔드 시험: 543개 성공
- `compileall`, `git diff --check`: 성공
- 기존 사용 중단 예정 경고 7개, 새 경고 없음

## 남은 위험

- 무마커 기존 양식의 여러 쪽 특징점 후보 차이는 합성 자료로만 구현되어 실제 양식 묶음 측정이 필요하다.
- 로컬 이름 인식 실행 파일이 현재 기기에 없어 실제 이름 표본의 파이프라인 통합 확인은 남아 있다.
