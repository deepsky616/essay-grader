  • 같은 기기와 같은 브라우저에서만 다시 열 수 있습니다.
  • 브라우저 데이터를 지우면 저장된 평가도 함께 삭제됩니다.

  • 학생 명단·수업·설계·답안·채점 결과는 현재 브라우저에 저장하며 다른 기기와 동기화되지 않습니다.
  • 개인정보 최소 전송 모드에서는 페이지 분석 명단에서 이름을 제외하고, 채점에는 익명 번호만 사용합니다.
