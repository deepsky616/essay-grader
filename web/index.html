GitHub Pages 작동 방식

파일은 이 브라우저 안에만 저장됩니다.

GitHub Pages는 정적 호스팅이어서 서버 데이터베이스나 비밀 API 키를 둘 수 없습니다. 이 버전은 선택한 파일을 브라우저의 IndexedDB에 저장하며 GitHub 저장소로 전송하지 않습니다.

  • 같은 기기와 같은 브라우저에서만 다시 열 수 있습니다.
  • 브라우저 데이터를 지우면 저장된 평가도 함께 삭제됩니다.
  • AI 자동 채점은 보호된 별도 서버 API를 연결한 뒤 사용할 수 있습니다.
