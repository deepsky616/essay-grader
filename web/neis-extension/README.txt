AI 서·논술형 NEIS 입력 도우미 1.1.0

1. 이 폴더를 컴퓨터에 보관합니다.
2. Edge에서는 edge://extensions, Chrome에서는 chrome://extensions를 엽니다.
3. 개발자 모드를 켜고 '압축해제된 확장 프로그램을 로드'를 선택합니다.
4. 이 폴더를 선택합니다.
5. AI 서·논술형 평가지원시스템을 새로고침합니다.

사용 방법
1. 같은 Chrome 또는 Edge에서 NEIS 성취기준별 평가 화면과 평가지원시스템을 엽니다.
2. NEIS에서 학급·교과·영역·성취기준을 조회합니다.
3. 평가지원시스템의 NEIS 교과평가 입력 도우미에서 학생을 선택하고
   'NEIS 단계 자동 입력'을 누릅니다.
4. NEIS 탭 오른쪽에 열린 패널에서 학급과 학생 수를 확인하고
   '자동 입력 시작'을 누릅니다.
5. 왼쪽 NEIS 표에 단계가 번호 순서대로 입력되는 모습을 확인합니다.
6. 입력 완료 후 교사가 NEIS 단계와 평가결과를 확인하고 저장을 직접 누릅니다.

오른쪽 패널이 자동으로 열리지 않으면 NEIS 탭에서 브라우저 도구 모음의
확장 프로그램 아이콘을 누르고 이 도우미를 선택합니다. 브라우저 창을 두 개
열 필요는 없습니다.

이 확장 도우미는 다음 두 주소에서만 작동합니다.
- https://deepsky616.github.io/essay-grader/
- https://*.neis.go.kr/

학생 자료는 외부 서버로 보내거나 저장하지 않습니다. 현재 열린 NEIS 성취기준별
평가 화면에서 학생 번호와 이름을 모두 대조한 뒤 오른쪽 패널에서 '단계' 값만
번호 순서대로 입력하며, NEIS의 저장 버튼은 누르지 않습니다.
