NEIS 입력 도우미 설치

AI 서·논술형 평가지원시스템에서 확정한 학생별 성취수준을 현재 열린 NEIS 성취기준별 평가 화면의 단계 칸에 입력합니다. NEIS 표는 왼쪽에 그대로 보이고, 자동 입력 진행 상황은 오른쪽 패널에서 확인할 수 있습니다.

확장 도우미 ZIP 내려받기평가지원시스템으로 돌아가기
개인정보 보호
학생 명단과 성취수준은 이 컴퓨터의 두 탭 사이에서만 전달됩니다. 외부 서버 저장·전송 기능이 없고 NEIS의 저장 버튼도 누르지 않습니다.

1. ZIP 압축 풀기

  1. 확장 도우미 ZIP 내려받기를 누릅니다.
  2. 다운로드한 neis-extension.zip을 마우스 오른쪽 버튼으로 누르고 압축 풀기를 선택합니다.
  3. 압축을 푼 폴더는 삭제하지 말고 교사용 컴퓨터의 안전한 위치에 보관합니다.

2. 사용하는 브라우저에 설치

Microsoft Edge

  1. 주소창에 edge://extensions 입력
  2. 개발자 모드 켜기
  3. 압축 풀린 확장 로드 선택
  4. 압축을 푼 폴더 선택

Google Chrome

  1. 주소창에 chrome://extensions 입력
  2. 개발자 모드 켜기
  3. 압축해제된 확장 프로그램을 로드합니다 선택
  4. 압축을 푼 폴더 선택

3. 사용 전 체크

  • 평가지원시스템과 NEIS를 같은 Chrome 또는 Edge에서 열었습니다.
  • 평가지원시스템 페이지를 새로고침했습니다.
  • NEIS 탭은 입력할 화면 하나만 열었습니다.
  • NEIS에서 학년·반·교과·영역·성취기준을 조회했습니다.
  • 교사 확정 결과와 학생 수를 확인했습니다.

4. NEIS 화면을 보면서 입력

  1. 평가지원시스템의 NEIS 교과평가 입력 도우미에서 학생을 선택하고 NEIS 단계 자동 입력을 누릅니다.
  2. 번호·이름·단계 대조가 끝나면 브라우저가 NEIS 탭으로 이동하고, 화면 오른쪽에 입력 패널이 열립니다.
  3. 오른쪽 패널의 학급·교과·평가·학생 수를 확인하고 자동 입력 시작을 누릅니다.
  4. 오른쪽 진행률과 현재 학생을 확인하면서 왼쪽 NEIS 표의 단계가 번호 순서대로 채워지는지 봅니다.
  5. 완료 후 단계와 평가결과를 확인하고 NEIS의 저장을 직접 누릅니다.

오른쪽 패널이 자동으로 열리지 않으면 NEIS 탭에서 브라우저 도구 모음의 확장 프로그램 아이콘을 누른 뒤 ‘AI 서·논술형 NEIS 입력 도우미’를 선택하세요. Chrome 창을 두 개 열 필요는 없습니다.

안전하게 동작하는 방식

도우미는 먼저 모든 학생의 번호 + 이름 + 단계 선택값이 정확히 한 번씩 일치하는지 검사합니다. 대조가 끝난 뒤에만 오른쪽 패널의 시작 버튼이 활성화되며, 학생 번호 순서대로 한 명씩 입력합니다. 진행 중 중단할 수 있고 NEIS의 저장 버튼은 누르지 않습니다.

기관별 NEIS 화면 구조가 달라 자동 입력이 중단되면 평가지원시스템의 ‘번호·성취수준 복사’ 또는 ‘NEIS 확인용 Excel’을 사용해 주세요.
